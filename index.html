Installation

Follow these commands in your Termux terminal.

Termux Terminal
$ pkg update && pkg upgrade $ pkg install wget $ echo "deb [trusted=yes] https://speed494.github.io/kraze-repo stable main" >> $PREFIX/etc/apt/sources.list $ pkg update
